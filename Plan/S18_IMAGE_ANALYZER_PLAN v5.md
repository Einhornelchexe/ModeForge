## 0. Auftrag

Browserlokaler Einzelbild-Beam-Profil-Analyzer (TIFF/PNG-Import, Diagnostik, Hintergrundkorrektur, ROI, Momente, Profile, Fits beliebiger Strahlformen inkl. Super-Gauss, Export) als neue Workbench-Faehigkeit. Verbindliche Randbedingung: Die Verwendung der einschlaegigen DIN-EN-ISO-Verfahren wurde von der zustaendigen Stelle nicht gestattet; der Analyzer ist ein eigenstaendig definierter, vollstaendig oeffentlich dokumentierter Auswerteweg ohne jede Norm-Behauptung.

## 1. Zielbild & Normfreiheit

Sechster Workbench-Tab, vollstaendig browserlokal. Alle Methoden bilden den "ModeForge-Auswerteweg" (docs/theory/image_analysis.md) mit Verweisen auf oeffentliche Literatur; **Norm-Dokumente werden bewusst weder benannt noch zitiert**. Terminologie: bestehendes Produktvokabular ("D4sigma diameter", "Suggested ROI", "numerische Sensitivitaet"). Keine Norm-Eigenschaftsbehauptung in Produktoberflaechen (Gate Abschnitt 8; verneinende Schutzklauseln per Allowlist). Keine M2-Bestimmung aus mehreren Ebenen; keine normativen Pruefberichte; keine Aussage "messtechnisch gueltig". Kaustik-Fit-Tab unberuehrt.

## 4. S18b - Hintergrund + ROI + Momente + Stabilitaet

- `src/background.ts`:
  - none | Dunkelbild (Dimensions-+dtype-Gleichheit, f32 gehalten) | manueller Offset | Hintergrund-Rechtecke | robuste geneigte Ebene.
  - **EINE Rauschskala sigma_B_hat** (drei bisherige Rollen vereinheitlicht) — **REVIDIERT 2026-08-17 (v5.1) nach Opus-Gegenlese (Plan/S18_IMPL_REVIEW_S18B.md, B4/B5: Stdabw-Fallback nicht robust, min-max-Floor ausreisserdominierbar):** sigma_B_hat = max(robusteSkala, floor) mit robuster Kaskade robusteSkala = 1.4826*MAD(Referenzpixel), bei MAD=0 -> IQR/1.349 (alle dtypes), bei IQR=0 -> 0 (KEIN Stdabw-Fallback mehr); floor = halber Quantisierungsschritt (Integer) bzw. 1e-12*robuste Dezilspanne P90-P10 der Samples (Float, nearest-rank, von Einzelausreissern unbeeinflusst); Referenzpixel = Nutzer-Rechtecke (Ueberlappung pixel-dedupliziert), sonst dokumentierter ROI-Randrahmen; Ausweis von iqrCounts + scaleSource (mad|iqr|floor|zero). **sigma_B_hat = 0 ist moeglich (konstantes Bild) — alle davon abhaengigen Groessen sind dann null, nie Infinity.**
  - Ebene: NUR auf Hintergrundpixeln (Rechtecke oder Randrahmen), Rang-/Konditions-Guard + **Leverage-Guard (robuste Koordinatenstuetzung: P90-P10 der x- und y-Koordinaten je > 0; ein Einzelpixel traegt nie allein eine Steigung — B3)**, zentrierte Koordinaten, LS-Start, IRLS-Huber mit **wertskalen-verankertem delta = 1.345*max(1.4826*MAD(Residuen), anchorFloor); anchorFloor = 0.5 counts (Integer) bzw. 1e-6*Dezilspanne der Fit-WERTE (Float32, ueber dem f32-Epsilon — kein Gewichtskollaps auf Rundungsresiduen mehr; B1/B2)**, alle |Residuen| <= anchorFloor -> konvergiert, per-Parameter-Skalen, 50-Iterationen-Force-Exit (unter dem Anker praktisch unerreichbar, dokumentiert), Ebenen-Referenzzentrum xMeanPx/yMeanPx im Ergebnis (M8). Skalen-Orakel: exakte Skalierung 1e-12; Requantisierungs-Konsistenz lose.
  - Negative Werte nach Korrektur: nie geklippt; Anteil berichtet.
- **Momentenanalyse — dreistufig ausgewiesen, hart getrennt (R4-messgestuetzt):**
  - **Gueltigkeitspraedikat (positiv formuliert, je Stufe auf deren eigener Domaene ausgewertet):** gueltig <=> Number.isFinite aller Aggregate UND Summe(I_corr) > 0 UND Summe(I_corr) >= 0.01*Summe(|I_corr|) (Groessenordnungs-Guard gegen hintergrunddominierte Domaenen) UND lambda_min >= 0 UND lambda_max > 0. **Auswertungsreihenfolge mit Kurzschluss: erst Summen pruefen; bei Verletzung KEINE lambda-Berechnung, alle Groessen null + IMAGE_MOMENTS_UNDEFINED.** (Die v4-Negationsform !(x<=0) war NaN-akzeptierend — R4/G4-H1+P4-H1.)
  - **Stufe A — ROI-Momente (Sektion `momentsRoiDiagnostic`):** vorzeichenbehaftete Second-Moments ueber der bestaetigten ROI. Ehrlich als Diagnostik gelabelt — R4-Messlage: auf Full-Frame bei ueblichem SNR zu ~78 % ungueltig, Ueberlebende median +121..+221 % verzerrt. Traegt den ROI-Sweep (unten).
  - **Stufe B — Blenden-Momente (Sektion `moments`, der Default-Ausweis):** Second-Moments innerhalb der Ellipse mit Halbachsen alpha*sigma_Fit (alpha Default 4) um das Fit-Zentrum des 2D-GAUSS-Basisfits (immer der Gauss-Fit, auch wenn Super-Gauss zugeschaltet ist — zu grosse Blende ist quasi gratis, zu kleine teuer; R4/P4-M6+L2); **Momentenbezugspunkt = Zentroid INNERHALB der Blende** (R4/P4-M7). R4-Messlage: rekonstruiert D4sigma ROI-unabhaengig (Median-Bias -0.14..-0.36 %, Gauss-Trunkierung exakt -0.13432 % bei alpha=4, unkorrigiert ausgewiesen und dokumentiert).
  - **Freigabe-Gates der Stufe B (alle muessen bestehen, sonst bleibt `moments` null mit maschinenlesbarem Unterdrueckungsgrund — NIE Substitution durch Stufe A):**
    1. 2D-Gauss-Fit konvergiert (Status ok).
    2. Rausch-relative Residuenschwelle: RMS_Residuum <= max(2*sigma_B_hat, 0.5 % vom Peak) (die v4-Peak-relative 5-%-Schwelle war bei SNR 20 ein Rauschdetektor — R4/P4-H2).
    3. **Alpha-Konsistenz-Gate:** |D4sigma(alpha=4) - D4sigma(alpha=6)| / D4sigma(alpha=6) <= 3 % (ein zusaetzlicher Momentenpass; trennt gauss-artige Profile (<~1 %) von fluegel-lastigen: Zweikeulen ~37 %-Punkte, Core+Halo ~10, Super-Gauss n<1 ~3.6 — R4/P4-H3+H5).
    4. Kein MULTI_PEAK-Befund.
  - **Geltungsbereich ehrlich dokumentiert:** Der Blenden-Ausweis gilt fuer kompakte, im Kern gauss-artige Strahlen; fluegel-lastige/multimodale Profile werden ERKANNT und der Ausweis unterdrueckt (docs/theory mit den R4-Messzahlen inkl. Restsockel-Reihe: delta=1 % Sockel -> +10.4 % — die Blende daempft Pedestal-Fehler um ~2 Groessenordnungen, eliminiert sie nicht). **Rest-Sockel-Indikator:** mittleres I_corr ausserhalb der Blende relativ zum Peak wird ausgewiesen; ueber Schwelle -> Hinweis "Hintergrundkorrektur pruefen".
  - **Stufe C — Fit-Breite 4*sigma_Fit** (Sektion `fits`): bei gauss-artigen Strahlen der praeziseste Wert (R4: sd 3-4x kleiner als Stufe B); als eigenstaendige, modellgebundene Zahl gelabelt.
- `src/roi.ts`: full-frame, manuell, Suggested-ROI (Maske I_corr > k*sigma_B_hat, groesste zusammenhaengende Region, BBox+Padding; nur Vorschlag, userConfirmed).
- **ROI-Stabilitaetsanalyse (Stufe-A-Indikator, ohne 2D-Fit):** Hintergrund wird EINMAL auf der Primaer-Konfiguration bestimmt; der Sweep variiert NUR die Auswertegeometrie auf dem statisch korrigierten Bild (R4/G4-M2+P4-M11). Groessen 0.8/0.9/1.0/1.1/1.2x + Shifts +-5 % (physisch bei Kalibrierung); Randfenster Clamp+Shrink geflaggt; Voll-Frame: nur Shrink-Varianten, size-only gelabelt, **"nicht bestimmbar" ist dort der Regelfall und wird als solcher angezeigt, kein Fehler** (R4/P4-M2: 4-6/50 erfuellen die 3-Varianten-Regel). Sensitivitaet nur ueber gueltige Varianten; <3 gueltige -> "nicht bestimmbar" + Warnung. **Stabilitaetsindikator der Stufe B ist das Alpha-Konsistenz-Delta** (der Sweep gilt nur fuer Stufe A — ehrlich gelabelt; R4/P4-M1).

Orakel (erweitert um die R4-Fehlermodi): Ebene rauschfrei <1e-9 + Skalen-/Requantisierungs-Orakel + Degenerationsfaelle; **P3-H1-Regression: Blenden-Momente rekonstruieren D4sigma innerhalb dokumentierter Toleranz unter Full-Frame-/SNR-Bedingungen, unter denen Stufe A nachweislich versagt**; Praedikats-Randfall-Matrix (NaN, +-Inf, Summe 1e-300, lambda_min=0-Linie, hintergrunddominiert); Nicht-Gauss-Unterdrueckung (Zweikeulen, Core+Halo, Donut -> Stufe B null + Grund); Fallback-Pfad-Ausweis (Fit scheitert -> `moments` null, Diagnostik-Sektion gefuellt); Restsockel-Reihe; alpha-Sweep; Trunkierungsformel alpha in [2,6] gegen geschlossene Form; Full-Frame-Aggregationsregel; MAD-/Floor-/sigma=0-Faelle; Suggested-ROI; Determinismus.

## 5. S18c - Peaks/Profile

- `src/moments.ts`: Schwerpunkt; Kovarianz -> lambda1/lambda2 + `thetaRad` (sigma1>=sigma2, theta in [0,pi)); q nur unter dem Praedikat der jeweiligen Stufe; IMAGE_ORIENTATION_UNSTABLE bei q<0.05; **Hinweis-Warnung bei sigma_minor < 1 px ("Achse nicht aufgeloest" — Linien-Degeneration liefert sonst kommentarlos D4sigma_minor=0)**; D4sigma je Stufe. Peaks raw/korrigiert; Subpixel (2x 3-Punkt-Parabeln, Guards: Nenner<=0, |Verschiebung|>0.5 px, Saettigung, Rand; Gueltigkeit ab w>=3 px, Bias dokumentiert).
- `src/profiles.ts`: Schnitte, Projektionen, Achsen-Profile (bilinear, physisch bei Kalibrierung). **FWHM nur wenn I_peak_corr > 3*sigma_B_hat** (sonst null + Warnung — Scheinschnitte im Rauschen; R4/G4-M1+P4-M10); Basislinie: Schnitt bei I_peak_corr/2; Mehrfach-Schnitte -> IMAGE_FWHM_AMBIGUOUS. Strikte Trennung FWHM(Daten)/FWHM(Fit)/1-ueber-e2/Second-Moment.

Orakel: wie v4 + FWHM-Signal-Guard-Faelle (delta-Reihe inkl. I_peak_corr<=0), Subpixel-Degeneration.

## 6. S18d - Fits + Kenngroessen

- `src/fit.ts`: eigene LM-Implementierung (analytische Jacobians, Marquardt, Parameter-Skalierung, skalenbewusste Konvergenz, Cap 30 Iterationen + Zeitbudget, Status ehrlich). **Startwerte MOMENTENFREI und robust: Peak-Position (korrigiert) + Halbwertsflaechen-Schaetzung fuer sigma/Amplitude; gueltige ROI-Momente dienen nur als optionale Verfeinerung** (R4/P4-H4: momentenfreier Start konvergiert 48-50/50 inkl. Full-Frame, median 7-8 Iterationen; der v4-Momenten-Start existierte dort nur in 22-26 %). Fit-Gebiet ROI; je Achse > 512 -> 2^k-Mittelwert-Pooling mit Breiten-Korrektur w = sqrt(w_fit^2 - b^2/3) und Koordinaten-Rueckabbildung x_full = b*x_dec + (b-1)/2; IMAGE_FIT_DECIMATED (info).
- Modelle: 1D-Gauss; rotierter elliptischer 2D-Gauss (Hintergrund konstant/geneigt mitgefittet); Super-Gauss exakt: I = B + A*exp(-2*((u/w1)^2+(v/w2)^2)^n) (fuer w1=w2 identisch mit packages/beams/src/profiles.ts:51; Bounds [0.5,10]; Exponent geclampt); sigma/w = sqrt(2^(-1/n)*Gamma(2/n)/(2*Gamma(1/n))) (Gamma test-only via Lanczos). Kanonisierung wie §5.
- Kalibrierung anisotropiefest (physische Koordinaten fuer ALLE mm-Groessen; C' = S C S^T; A' = S^-T A S^-1, Breiten = 1/sqrt(Eigenwerte), Winkel aus Eigenvektoren).
- Ausgaben: Parameter; Residuen-Statistik full-res (RMS/Max) + Anzeige-Grid <= 256^2; Residuenprofile; **RESIDUAL_HIGH rausch-relativ: RMS > max(2*sigma_B_hat, 0.5 % Peak)** (R4/P4-H2); Fit- vs. Momentenbreiten-Vergleich (Super-Gauss via Gamma-Formel; n<1 tail-limitiert markiert); Modellvergleich als relative RMS-Reduktion; **Peak-to-Background-Noise = I_peak_corr / sigma_B_hat NUR wenn sigma_B_hat > 0 UND I_peak_corr > 0, sonst null** (R4/P4-M9). "Numerische Sensitivitaet"-Sprache.
- `src/metrics.ts`: Elliptizitaet, PtBN (mit Guard), eingeschlossene Leistung, radiale Verteilung, Multi-Peak, Symmetriefehler, Modellvergleich, Clipping, Hot-Pixel-Anteil, Rest-Sockel-Indikator (§4).
- Budgets: O(N)-Paesse + Sweep < 1 s @2048^2 (R3: 18.6 ms/Momentenpass); 2D-LM auf Fit-Gitter <= 512^2, Cap 30 (R3: 68 ms/Iteration @512^2; R4: median 7-8 Iterationen) < ~2 s inkl. Browser-Marge; Gesamt < 5 s @2048^2. Working-Set <= 400 MiB @4096^2 itemisiert (Dateibytes nach Decode frei, Original 1x, F64-Arbeitspuffer wiederverwendet, Dunkelbild f32, Labels transient, Grids <= 256^2). IMAGE_SIZE_BLOCKED bei Allokationsfehler; Pixel-Cap 4096^2.

Orakel: wie v4 + momentenfreier Start-Regressionsfall (Full-Frame-Konvergenz), rausch-relative Residuenschwelle (perfekter Gauss bei SNR 20 feuert NICHT — R4/A5-Regression), Dezimierung gegen Synthetik-Truth, Cross-Check zirkularer Super-Gauss gegen packages/beams.
