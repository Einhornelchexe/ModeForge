Sechster Workbench-Tab, vollstaendig browserlokal. ## 4. S18b - Hintergrund + ROI + Stabilitaet

- `src/background.ts`:
  - none | Dunkelbild (Dimensions-+dtype-Gleichheit, sonst IMAGE_DARK_MISMATCH; wird als float32 gehalten) | manueller Offset | Hintergrund-Rechtecke (Mittelwert/Median/Stdabw/MAD; sigma_B_hat = max(1.4826*MAD, floor); floor: Integer = halber Quantisierungsschritt, Float = 1e-12*(max-min); MAD=0 bei Float -> Stdabw-Fallback) | robuste geneigte Ebene.
  - **Ebene, vollstaendig inkl. Domaene:** gefittet wird NUR auf Hintergrundpixeln — Nutzer-Rechtecke oder (ohne Markierung) ein dokumentierter ROI-Randrahmen; Rang-/Konditions-Guard verlangt Ausdehnung in beiden Achsen (1-px-Streifen -> Fehler mit Hinweis). Zentrierte Koordinaten; Start = LS; IRLS-Huber delta = 1.345*sigma_hat, sigma_hat = max(1.4826*MAD(Residuen), floor wie oben), nachgefuehrt; alle |Residuen| <= floor -> konvergiert; Abbruch bei **per-Parameter-Skalen** (Offset: Datenspanne; Steigungen: Datenspanne/Rahmen-Ausdehnung) |dp| <= 1e-10*Skala, oder 50 Iterationen (Force-Exit).
  - **Skalenverhalten:** Orakel 1: exakte Skalierung I -> a*I => Ebene skaliert mit a (1e-12). Orakel 2: 8- vs 16-bit-Requantisierung derselben Szene => Konsistenz mit dokumentierter, loser Toleranz (Requantisierung ist KEINE Skalierung).
  - Negative Werte nach Korrektur: nie geklippt; Anteil berichtet.
- **Momentenanalyse, zweistufig (revidiert nach R3/P3-H1 — Monte-Carlo-Befund: reine ROI-Momente sind bei grosser ROI rausch-dominiert):**
  1. **ROI-Momente** (transparent): vorzeichenbehaftete Second-Moments ueber der bestaetigten ROI. **EIN Gueltigkeitspraedikat fuer ALLE Momentengroessen** (NaN-robust negiert formuliert): gueltig <=> !(Summe der endlichen I_corr <= 0) UND !(lambda_min < 0) UND !(lambda1+lambda2 <= 0); ungueltig -> alle Momentengroessen (Schwerpunkt-abgeleitete Breiten, sigma, q, Winkel) null + IMAGE_MOMENTS_UNDEFINED. NaN-Pixel sind vorab ausgeschlossen (Abschnitt 3).
  2. **Blenden-Momente (Default-Ausweis, ModeForge-Verfahren):** Second-Moments innerhalb der Ellipse mit Halbachsen alpha*sigma_Fit (aus dem konvergierten 2D-Fit; alpha Default 4, konfigurierbar), Zentrum = Fit-Zentrum. Rausch-robust, weil die Rauschflaeche auf die Signalskala begrenzt ist. **Dokumentierte Grenze: Gauss-Trunkierungsfehler bei alpha=4 exakt herleitbar, < 0.15 % in sigma; fuer Nicht-Gauss-Profile als Naeherung markiert.** Fallback-Kette: Fit nicht konvergiert oder Residuum hoch -> ROI-Momente + Warnung. Full-Frame-ROI-Momente werden als "diagnostisch" gelabelt (nicht als Mess-Ausweis) + Warnung.
  - UI/Result zeigen beide Stufen nebeneinander (D4sigma_ROI, D4sigma_Blende) samt Sweep-Sensitivitaet; docs/theory dokumentiert das Rausch-Flaechen-Gesetz und warum es zwei Stufen gibt.
- `src/roi.ts`: full-frame, manuell, Suggested-ROI. **Alle Schwellen operieren auf I_corr (B_eff = 0 nach Korrektur):** Maske I_corr > k*sigma_hat; sigma_hat je Methode (Rechtecke: deren MAD; sonst MAD ueber den ROI-/Bild-Randrahmen, dokumentiert). Groesste zusammenhaengende Region, BBox + Padding; nur Vorschlag (userConfirmed, sonst IMAGE_ROI_UNCONFIRMED).
- ROI-Stabilitaetsanalyse (ohne 2D-Fit): Groessen 0.8/0.9/1.0/1.1/1.2x + Shifts +-5 % (physische Koordinaten bei Kalibrierung); Randfenster Clamp+Shrink geflaggt. **Voll-Frame: Groessen- UND Shift-Vergroesserungen entfallen — nur Shrink-Varianten, als size-only gelabelt.** **Aggregationsregel:** Sensitivitaet nur ueber Varianten mit gueltigen Momenten; < 3 gueltige Varianten -> Sensitivitaet "nicht bestimmbar" + Warnung. IMAGE_ROI_SENSITIVE ueber Schwelle (Tabelle Abschnitt 7).

Orakel: Ebene rauschfrei < 1e-9 (zentriert, Hintergrundpixel-Domaene); exakte Skalen-Aequivarianz 1e-12; Requantisierungs-Konsistenz (lose); MAD-/Floor-/Degenerationsfaelle (1-px-Rechteck -> Fehler); Hot-Pixel-Robustheit; **verrauschte Synthetik: Blenden-Momente rekonstruieren D4sigma innerhalb dokumentierter statistischer Toleranz bei Full-Frame-Bedingungen, unter denen die ROI-Momente nachweislich versagen (Regressionsfall gegen P3-H1)**; NaN-Guard-Test (NaN-Pixel im Bild -> definiertes Verhalten statt NaN-Kaskade); Suggested-ROI trifft Ground-Truth; Sensitivitaeten deterministisch.

## 5. S18c - Momente/Peaks/Profile

- `src/moments.ts`: Schwerpunkt; Kovarianz -> lambda1/lambda2 + `thetaRad` (sigma1 >= sigma2, theta in [0, pi)); q nur unter dem EINEN Gueltigkeitspraedikat (Abschnitt 4); IMAGE_ORIENTATION_UNSTABLE bei q < 0.05; D4sigma = 4*sigma je Stufe (ROI/Blende). Peaks raw/korrigiert.
- Subpixel-Peak: zwei separable 3-Punkt-Parabeln auf I; Guards: nicht-konkaver Nenner (<= 0) oder |Verschiebung| > 0.5 px -> unterdrueckt; Saettigung in 3x3 -> unterdrueckt; Bildrand -> unterdrueckt (EDGE_TOUCH-Kopplung); Gueltigkeit ab w >= 3 px, Bias dokumentiert (rauschfrei <= 0.022 px — R3-nachgemessen 0.02134).
- `src/profiles.ts`: Schnitte durch Peak/Schwerpunkt, Projektionen, Moment-/Fit-Achsen-Profile (bilinear; physische Koordinaten bei Kalibrierung). **FWHM-Basislinie auf korrigierten Daten: Schnitt bei I_peak_corr/2** (B_eff=0-Semantik); Mehrfach-Schnitte/Multi-Peak -> IMAGE_FWHM_AMBIGUOUS. Strikte Trennung FWHM(Daten)/FWHM(Fit)/1-ueber-e2/Second-Moment.

Orakel: rauschfrei < 1e-9, verrauscht seeded-statistisch; Subpixel < 0.05 px (w >= 3 px) + Degenerationsfaelle (Plateau, Rand); FWHM = w*sqrt(2*ln2) + Fall mit konstantem Hintergrund (nach Korrektur).

## 6. S18d - Fits + Kenngroessen

- `src/fit.ts`: eigene LM-Implementierung (analytische Jacobians, Marquardt-Daempfung, Parameter-Skalierung, skalenbewusste Konvergenz, **Iterations-Cap 30** + Zeitbudget, Status ehrlich). **Fit-Gitter: jede ROI-Achse > 512 wird per 2^k-MITTELWERT-POOLING (Block-Mittel) je Achse auf <= 512 gebracht** (deterministisch; IMAGE_FIT_DECIMATED als Info). **Breiten-Korrektur dokumentiert: w = sqrt(w_fit^2 - b^2/3) je Achse (Gauss exakt; Super-Gauss als Naeherung markiert); Koordinaten-Rueckabbildung x_full = b*x_dec + (b-1)/2.** Momente/Diagnostik bleiben full-res.
- Modelle: 1D-Gauss; rotierter elliptischer 2D-Gauss (x0, y0, A, w1, w2, theta; Hintergrund konstant/geneigt mitgefittet); **Super-Gauss EXAKT definiert: I = B + A*exp(-2*((u/w1)^2 + (v/w2)^2)^n)** (radiale Potenz; fuer w1=w2 identisch mit packages/beams/src/profiles.ts:51; Start n=1, Bounds [0.5, 10]; Exponentenargument geclampt — bei n~10 unterlaufen exp/Jacobian jenseits ~1.5w). **sigma/w geschlossen: sigma = w*sqrt(2^(-1/n)*Gamma(2/n)/(2*Gamma(1/n)))** — R3 numerisch bestaetigt (n=1: 0.5 exakt); Gamma test-only via Lanczos. Startwerte aus Momenten; optionale Huber-Gewichtung; Kanonisierung wie Abschnitt 5.
- Kalibrierung (anisotropiefest): alle mm-Groessen in physischen Koordinaten; Momente C' = S C S^T; Fit-Quadratform A' = S^-T A S^-1, **Breiten = 1/sqrt(Eigenwerte von A')**, Winkel aus Eigenvektoren; FWHM/Profile/eingeschlossene Leistung/Sweep-Shifts physisch. IMAGE_ANISOTROPIC_PIXELS (info) bei pitchX != pitchY; ohne Kalibrierung px-Felder + IMAGE_CALIBRATION_MISSING (info).
- Ausgaben: Parameter; Residuen-Statistik full-res (RMS/Max) + Anzeige-Grid <= 256x256 (Abschnitt 7); Residuenprofile; Fit- vs. Momentenbreiten (Umrechnung je Modell; Super-Gauss via Gamma-Formel; Momentenvergleich bei n < 1 tail-limitiert — markiert); Modellvergleich als relative RMS-Reduktion in %; **Peak-to-Background-Noise = I_peak_corr / sigma_hat** (ersetzt Peak-to-Background; immer definiert wenn sigma_hat > 0). "Numerische Sensitivitaet"-Sprache durchgaengig.
- `src/metrics.ts`: Elliptizitaet, Peak-to-Background-Noise, eingeschlossene Leistung, radiale Verteilung, Multi-Peak, Symmetriefehler, Modellvergleich, Clipping, Hot-Pixel-Anteil.
- **Budgets (revidiert nach R3-Messungen: 240.9 ms/LM-Iteration @1024^2, 68.1 ms @512^2; 18.6 ms/Momentenpass @2048^2):** O(N)-Paesse + Sweep < 1 s @2048^2; 2D-LM auf Fit-Gitter <= 512^2 mit Cap 30 Iterationen < ~2 s in Node, Browser-Marge dokumentiert; Gesamt-Ziel < 5 s @2048^2. **Working-Set itemisiert, Ziel <= 400 MiB @4096^2:** Dateibytes nach Decode freigegeben, Original 1x, transienter F64-Arbeitspuffer wiederverwendet, Dunkelbild f32, Label-/Masken-Puffer transient, Anzeige-Grids <= 256^2. Allokationsfehler -> IMAGE_SIZE_BLOCKED. Pixel-Cap 4096x4096.

Orakel: 2D-Rekonstruktion < 1e-6 rel (deutlich elliptisch, w1/w2 >= 1.3); runder Fall rotationsinvariant; n-Rekonstruktion; sigma(w, n) gegen Gamma-Formel UND hochaufgeloeste Integration; **Cross-Check image vs packages/beams NUR im zirkularen Fall (die Repo-Funktion ist radial-skalar — die elliptische Verallgemeinerung ist bewusst die hier definierte)**; **Dezimierungs-Orakel gegen Synthetik-TRUTH (nicht gegen Full-res-Fit): gepoolter Fit + Breiten-Korrektur trifft Wahrheit innerhalb w-/b-abhaengiger, dokumentierter Toleranzen — Suite bleibt schnell**; Nichtkonvergenz ehrlich; Residuen-RMS gegen Rauschniveau; anisotroper Testfall.
